# GTA VI Landing Page Replica

A full-scale, high-fidelity project replicating the immersive, cinematic animations expected of a major AAA product launch. This project serves as a deep dive into advanced frontend animation techniques, consolidating complex GSAP timelines, ScrollTrigger integrations, and sophisticated easing functions within a modern Next.js environment.

## ✨ Key Features

- **Cinematic Animations:** Full implementation of GSAP 3.13, utilizing `ScrollTrigger` for scroll-linked storytelling, complex nested timelines, and custom, sophisticated easing curves.
- **Immersive UI/UX:** High-performance rendering optimized for smooth 60fps animations, leveraging hardware acceleration and modern CSS.
- **Responsive Design:** Fluid layouts and adapted animation timelines for seamless experiences across desktop, tablet, and mobile devices (using `react-responsive`).
- **Modern Architecture:** Built on the bleeding edge of the React ecosystem with Next.js 16 and React 19.

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router)
- **UI Library:** [React 19](https://react.dev/)
- **Animation:** [GSAP 3.13](https://gsap.com/) & [@gsap/react](https://gsap.com/react/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Internationalization:** [next-intl](https://next-intl-docs.vercel.app/)
- **Utilities:** [react-responsive](https://www.npmjs.com/package/react-responsive)

## 🚀 Getting Started

To run this archived project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/gta-vi-landing.git
   cd gta-vi-landing
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser to view the project.

4. **Build for production:**
   ```bash
   npm run build
   npm start
   ```
